# タスク管理アプリ

日々のタスクを登録して一覧で見るための、小さな Web アプリです。
**ダミーデータだけで使ってください。** 実在の顧客名・案件名・社内システムの ID やパスワードは入れないでください。

## ファイル構成

`index.html` の 1 ファイルだけで動きます。中は 3 つの部分に分かれています。

| 部分 | 役割 | FileMaker で言うと |
|---|---|---|
| HTML（`<body>` の中） | 画面の骨組み（ヘッダー・ボード・入力用の小窓） | レイアウト |
| CSS（`<style>` の中） | 見た目（色・大きさ・スマホ用の並び方） | レイアウトの書式設定 |
| JavaScript（`<script>` の中） | 動き（登録・編集・削除・移動・並べ替え・保存） | スクリプト |

※ **HTML**＝画面の骨組みを書く言語、**CSS**＝見た目を指定する言語、**JavaScript**＝画面の動きを書くプログラム言語。

アイコンは **Lucide Icons**（無料で使えるアイコン集。ISC ライセンス）、英数字の書体は **Inter**（Google Fonts）をインターネットから読み込んでいます。ネットにつながっていないときは、アイコンが表示されず、書体が標準のものになります（機能はすべて動きます）。

## 使い方

画面は **カンバンボード**（「未着手」「進行中」「完了」の 3 列にタスクのカードを並べる形式）です。各列の上に件数、ヘッダーのタイトル横に未完了タスクの合計数が出ます。

- ［＋ 新規タスク追加］→ 入力用の小窓（**モーダル**＝画面の上に重なって出る小窓）が開きます
- カードを押す → 編集用のモーダルが開きます。［削除］は確認のあと削除します
- カードのステータスを変える方法は 2 つあります
  - **ドラッグ＆ドロップ**（PC のみ）：カードをマウスでつかんで、別の列の上で離す
  - **移動ボタン**：カード右下の［＜］で前の列へ、［＞］で次の列へ
- 「並び順」で各列の中の並べ替えができます
  - **期限が近い順**：期限日の早い順（期限なしは最後）。同じ日なら優先度の高い順
  - **優先度が高い順**：高 → 中 → 低。同じ優先度なら期限日の早い順
- ［ダミーデータに戻す］で最初の状態に戻ります

期限を過ぎた未完了のタスクは赤字、完了したタスクはグレーで表示されます。

### スマホでは

画面の幅が狭い（768px 以下）ときは、3 列を **タブ**（押して表示を切り替える見出し）で切り替えます。スマホではドラッグ＆ドロップが使えないので、［＜］［＞］ボタンで移動してください。

### PC では

1 画面に収まるように作っています。カードが増えたときは、その列の中だけがスクロールします。

## 自分のパソコンで試す

`app` フォルダの `index.html` をダブルクリックすると、ブラウザで開きます。
インターネットに公開しなくても、すべての機能が動きます。

## データの保存場所について（重要）

データは **localStorage**（ブラウザの中にある小さな保存場所）に保存されます。

- **端末・ブラウザごとに別々**です。PC で登録したタスクは、スマホでは見えません
- ブラウザの履歴やサイトデータを消すと、タスクも消えます
- プライベートモード（シークレットウィンドウ）では、ウィンドウを閉じると消えます

## インターネットに公開する（GitHub Pages）

**GitHub Pages**＝GitHub に置いたファイルを、そのまま Web サイトとして公開できる機能です。

> ⚠️ 無料プランでは、**リポジトリ**（GitHub 上のファイル置き場）を **public**（誰でも中身を見られる状態）にする必要があります。
> public にすると、このリポジトリのほかのファイル（ワークショップの配布物など）や、これまでの変更記録も公開されます。
> 公開してよいか、事前に確認してください。

1. 変更を GitHub に送ります（**プッシュ**＝手元の変更を GitHub に送ること）
2. GitHub でリポジトリを開き、［Settings］→［Pages］を開きます
3. 「Build and deployment」の **Source** で［Deploy from a branch］を選びます
4. **Branch**（変更の枝分かれ。普段は `main`）で `main` と `/ (root)` を選び、［Save］を押します
5. 1〜2 分待つと、ページ上部に公開 URL が表示されます
6. アプリは `公開URL/app/` で開けます（例：`https://＜アカウント名＞.github.io/＜リポジトリ名＞/app/`）

修正を反映するときは、再びプッシュします。反映まで 1〜2 分かかります。

## 用語集

| 用語 | 意味 |
|---|---|
| ブラウザ | Web ページを見るソフト（Chrome、Edge、Safari など） |
| URL | Web ページの住所（`https://〜`） |
| localStorage | ブラウザの中にある保存場所。そのブラウザだけで使える |
| レスポンシブ | 画面の幅に合わせてレイアウトが自動で変わる作り方 |
| リポジトリ | GitHub 上のファイル置き場 |
| コミット | 変更を記録すること（FileMaker の「保存」＋履歴メモのようなもの） |
| プッシュ | 手元で記録した変更を GitHub に送ること |
| ブランチ | 変更を本流とは別に進めるための枝分かれ |
| public / private | 誰でも見られる状態 / 許可した人だけが見られる状態 |
| カンバンボード | 作業の段階ごとに列を分け、タスクをカードで並べる表示形式 |
| モーダル | 画面の上に重なって出る小窓。閉じるまで後ろの画面は操作できない |
| ドラッグ＆ドロップ | マウスでつかんで（ドラッグ）、別の場所で離す（ドロップ）操作 |
| CDN | アイコンや書体などの部品を、インターネット経由で配っている置き場 |
